# paper-pokemon-tcg

Working draft of a paper on whether the Pokémon Trading Card Game is Turing complete.

**Status: draft in progress, not submitted and not yet reviewed.** It contains open TODO
notes, and some bibliography entries are marked unverified in `refs.bib`. The machine-checked
results it describes live in [sigilante/lean-pokemon](https://github.com/sigilante/lean-pokemon);
where the two disagree, the Lean source is authoritative.

Build: `latexmk -pdf mss.tex`. A compiled `mss.pdf` is kept in the repository and rebuilt with each change to the source.
